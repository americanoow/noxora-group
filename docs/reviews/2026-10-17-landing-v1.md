## Pontos para a revisão se concentrar

1. **`ContactForm.tsx`.** O formulário combina `action={formAction}` (sem JS) com `onSubmit` + `preventDefault` + `startTransition(formAction)` (com JS). Confirmar que:
   - não há envio duplo;
   - o React não reseta o formulário em caso de erro.
2. **`contact-action.ts`.** Verificar:
   - se a resposta de sucesso silenciosa ao honeypot é aceitável;
   - o tratamento de timeout e de erro do webhook;
   - se nada sensível é logado.
3. **Acessibilidade.** Conferir:
   - o padrão disclosure do menu mobile: os dois `nav` "Principal" nunca ficam visíveis ao mesmo tempo, pois o desktop fica oculto via CSS abaixo de `md`;
   - a região `aria-live` única do formulário;
   - o contraste de `text-muted` (#a1a1aa) sobre `surface` (#0b0b0d).
4. **Leitura de env no build.** `process.env` é lido em Server Components com `cacheComponents` ativo. Confirmar que é o comportamento desejado para `WHATSAPP_NUMBER`.
5. **Textos.** Verificar se algum texto promete resultado sem evidência.

## Limitações e pendências conhecidas

- **Documentos de origem vazios.** `docs/BRAND.md` e `docs/ROADMAP.md` estão vazios. A implementação seguiu o briefing da tarefa; paleta, tipografia (Geist + Instrument Serif) e textos são propostas a validar.
- **Marca.** Wordmark em texto (`Wordmark`, "NOXORA."), hero e favicon (`src/app/icon.png`, `apple-icon.png`) derivados de `public/images/noxora-icon.png`. Falta um SVG vetorial do logotipo.
- **Formulário.** Não entrega mensagens até `CONTACT_WEBHOOK_URL` ser configurada. Também não há rate limiting além do honeypot.
- **LGPD.** Falta a página de política de privacidade. A frase "Usamos seus dados apenas para responder a este contato" precisa de validação jurídica.
- **Conteúdo pendente.** Projetos (lista vazia), nomes, fotos e experiências da equipe (placeholders) e domínio final (`NEXT_PUBLIC_SITE_URL`).
- **Testes.** Não há auditoria automatizada com axe-core; a sugestão é adicionar `@axe-core/playwright` se a nova dependência for aprovada. O caminho de sucesso do webhook não tem teste e2e.
- **Dependência não usada.** `motion` está instalada mas não é usada; pode ser removida.
- **Core Web Vitals.** Não foram medidos com Lighthouse. A página é estática, sem imagens raster acima da dobra e com fontes auto-hospedadas.
